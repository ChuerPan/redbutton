# 别点红色按钮

一个像素风格的休闲点击游戏，考验你的勇气和运气！

## 项目概述

这是一个简单而刺激的像素艺术风格游戏，具有以下核心特点：

- **99%概率获得金币**，1%概率爆炸失败
- 支持主动结束游戏保存金币
- 完整的排行榜系统（支持本地和服务器）
- 本地存储 + 云端数据同步
- 像素金币城市动画系统
- 响应式设计，完美支持移动端

## 游戏规则

1. 点击【红色按钮】开始游戏
2. 99%概率获得100金币
3. 1%概率爆炸，游戏失败
4. 有1%的1%概率获得双倍金币（即200金币）
5. 长按1秒以上可自动点击
6. 只有"及时收手"才能结算金币
7. 每次获得金币，像素城市会逐渐建成！

## 技术栈

### 前端
- HTML5 + CSS3 (Tailwind CSS)
- Vanilla JavaScript
- Canvas (用于金币城市和趋势图)
- localStorage (数据持久化)
- 像素艺术UI风格
- ZCOOL QingKe HuangYou 字体（中文像素字体）

### 后端
- Node.js + Express
- SQLite 数据库
- 支持用户数据同步
- 云端排行榜

## 快速开始

### 环境要求

- 现代浏览器（支持 ES6+）
- 本地 HTTP 服务器（不能直接用 file:// 协议打开）
- Node.js 14+（如需运行后端服务）

### 运行方式

#### 方式一：前端游戏（单机模式）

```bash
# Python 3
python3 -m http.server 8000
```

#### 方式二：完整游戏（前端 + 后端）

```bash
# 1. 启动后端服务器
cd server
npm install
node init-db.js  # 首次运行需要初始化数据库
node server.js

# 2. 在另一个终端启动前端
cd ..
python3 -m http.server 8000
```

#### 方式三：使用 VS Code 插件

安装 "Live Server" 插件，右键点击 index.html 选择 "Open with Live Server"

### 访问游戏

启动服务器后，在浏览器中访问：

```
http://localhost:8000/index.html
```

后端 API 地址：
```
http://localhost:3001
```

管理后台：
```
http://localhost:3001/admin
```

## 游戏玩法说明

### 开始游戏

1. 打开游戏页面后，点击「开始游戏」按钮
2. 进入游戏界面后，点击屏幕下方的红色按钮
3. 每点击一次有 99% 的概率获得 100 金币
4. 获得金币后，像素城市会逐渐建成！

### 像素金币城市

- 每次获得金币，会在像素图案的空白格子中添加一个金币
- 图案随机（爱心、星星、月亮、钻石、骷髅、蘑菇、吃豆人、幽灵、三角力量等）
- 普通金币：金色外发光，到达格子后发光消失
- 双倍金币：紫色外发光，到达格子后保持发光
- 游戏失败时，金币城市会爆炸！

### 及时收手

- 当你觉得见好就收时，点击蓝色的「及时收手」按钮
- 结算当前金币，保存到排行榜
- 游戏结束，可以查看你的排名

### 游戏失败

- 当你触发那 1% 的概率时，游戏爆炸失败
- 所有金币损失，像素城市会爆炸
- 点击「重新开始」可以再次游戏

### 长按连点

- 长按红色按钮 1 秒以上，会自动每 0.3 秒点击一次
- 适合想要快速积累金币的玩家
- 当然风险也更大！

### 双倍奖励

- 极小概率（1%的1%）获得双倍金币（200金币）
- 会显示「奖励x2」的提示（显示1秒）
- 金币会有紫色外发光，并在城市中保持发光

## 数据统计

### 我的信息

在「我的信息」中可以查看：

- 玩家名称（可修改）
- 总的游戏次数
- 总的游戏失败次数
- 结束游戏最高金币
- 失败游戏最高金币
- 获得双倍金币次数
- 我的ID
- 地区
- 金币获取趋势图（最近10次游戏）

### 排行榜

排行榜显示排名前100的玩家：

- 第一名：金色
- 第二名：紫色
- 第三名：暗铜色
- 你的记录：蓝色高亮
- 各列文字居中显示

### 数据存储

- 本地：localStorage 持久化存储
- 云端：SQLite 数据库（服务器需要运行）
- 自动同步：在线时优先使用云端数据，离线时使用本地

## 开发说明

### 代码模块化

项目采用模块化设计，各文件职责明确：

- **state.js** - 游戏状态管理
- **game.js** - 核心游戏逻辑
- **ui.js** - UI 渲染和更新
- **cityBuilder.js** - ✨像素金币城市系统
- **ranking.js** - 排行榜功能
- **storage.js** - 数据持久化（本地+云端）
- **network.js** - 网络通信层
- **events.js** - 事件监听
- **utils.js** - 工具函数

### 像素风格

游戏采用像素艺术风格：

- 使用 Press Start 2P 字体（英文）
- 使用 ZCOOL QingKe HuangYou 字体（中文）
- 像素化按钮和边框样式
- 复古配色方案
- 像素金币绘制

### 后端 API

主要 API 接口：

- `POST /api/save-score` - 保存分数到排行榜
- `GET /api/leaderboard` - 获取排行榜
- `POST /api/save-user` - 保存用户数据（同时更新排行榜名称）
- `GET /api/user-info` - 获取用户数据

## 注意事项

- 必须通过 HTTP 服务器运行，不能直接打开 index.html
- 单机模式：数据存储在浏览器 localStorage 中
- 联网模式：数据同步到服务器，需要启动后端服务
- 新玩家第一次有效成绩后会提示输入名称
- 支持响应式布局，手机和电脑都可以正常游玩
