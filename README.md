# 别点红色按钮

一个像素风格的休闲点击游戏，考验你的勇气和运气！

## 项目概述

这是一个简单而刺激的像素艺术风格游戏，具有以下核心特点：

- **99%概率获得金币**，1%概率爆炸失败
- 支持主动结束游戏保存金币
- 完整的排行榜系统
- 本地存储数据持久化
- 响应式设计，完美支持移动端

## 游戏规则

1. 点击【红色按钮】开始游戏
2. 99%概率获得100金币
3. 1%概率爆炸，游戏失败
4. 有1%的1%概率获得双倍金币（即200金币）
5. 长按1秒以上可自动点击
6. 只有"及时收手"才能结算金币

## 技术栈

- HTML5 + CSS3 (Tailwind CSS)
- Vanilla JavaScript
- Canvas (用于金币趋势图)
- localStorage (数据持久化)
- 像素艺术UI风格

## 快速开始

### 环境要求

- 现代浏览器（支持 ES6+）
- 本地 HTTP 服务器（不能直接用 file:// 协议打开）

### 运行方式

#### 方式一：使用 Python

```bash
# Python 3
python3 -m http.server 8000
```

#### 方式二：使用 Node.js

```bash
# 安装 http-server
npm install -g http-server

# 启动服务器
http-server -p 8000
```

#### 方式三：使用 VS Code 插件

安装 "Live Server" 插件，右键点击 index.html 选择 "Open with Live Server"

### 访问游戏

启动服务器后，在浏览器中访问：

```
http://localhost:8000/index.html
```

## 游戏玩法说明

### 开始游戏

1. 打开游戏页面后，点击「开始游戏」按钮
2. 进入游戏界面后，点击屏幕下方的红色按钮
3. 每点击一次有 99% 的概率获得 100 金币

### 及时收手

- 当你觉得见好就收时，点击蓝色的「及时收手」按钮
- 结算当前金币，保存到排行榜
- 游戏结束，可以查看你的排名

### 游戏失败

- 当你触发那 1% 的概率时，游戏爆炸失败
- 所有金币损失
- 点击「重新开始」可以再次游戏

### 长按连点

- 长按红色按钮 1 秒以上，会自动每 0.3 秒点击一次
- 适合想要快速积累金币的玩家
- 当然风险也更大！

### 双倍奖励

- 极小概率（1%的1%）获得双倍金币（200金币）
- 会显示「奖励x2」的提示

## 数据统计

### 我的信息

在「我的信息」中可以查看：

- 玩家名称（可修改）
- 总的游戏次数
- 总的游戏失败次数
- 结束游戏最高金币
- 失败游戏最高金币
- 获得200金币次数
- 我的ID
- 金币获取趋势图

### 排行榜

排行榜显示排名前100的玩家：

- 第一名：金色
- 第二名：紫色
- 第三名：暗铜色
- 你的记录：蓝色高亮

所有数据通过 localStorage 本地持久化存储。

## 开发说明

### 代码模块化

项目采用模块化设计，各文件职责明确：

- **state.js** - 游戏状态管理
- **game.js** - 核心游戏逻辑
- **ui.js** - UI 渲染和更新
- **ranking.js** - 排行榜功能
- **storage.js** - 数据持久化
- **events.js** - 事件监听
- **coin.js** - 金币动画
- **utils.js** - 工具函数

### 像素风格

游戏采用像素艺术风格：

- 使用 Press Start 2P 字体
- 像素化按钮和边框样式
- 复古配色方案

## 注意事项

- 必须通过 HTTP 服务器运行，不能直接打开 index.html
- 数据存储在浏览器 localStorage 中，清除浏览器数据会丢失存档
- 支持响应式布局，手机和电脑都可以正常游玩
